# Fast Stop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop both recorders promptly, preserve all raw data and clock boundaries, let the next episode start, and defer raw validation/alignment to an explicit console action without video export.

**Architecture:** Remote stop commands only stop owned processes and release active markers. The desktop manifest atomically records `postprocess=pending` with complete stop, while a separate `finalize` CLI/console operation validates raw data and produces the alignment report after capture is idle. P450 video export remains manual.

**Tech Stack:** Python 3, pytest/unittest, PowerShell deployment, Bash on Unitree, local HTTP console.
