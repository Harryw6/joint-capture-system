# P450 / Unitree 联合采集与控制系统

本仓库保存 2026-09-29 从 Windows、P450、Unitree 实际部署环境收集的代码快照，包含现有未提交的采集修复。原工作目录、机器人程序及原始数据未被修改。

这是**私有恢复仓库**，不包含采集原始数据、真实会话 manifest、SSH 私钥、登录口令或控制令牌。保留恢复运行需要的设备路径、相机标识、网络配置和校准参数；不要直接改为公开仓库。

## 内容

| 目录 | 内容 |
| --- | --- |
| `controller/` | Windows 网页控制台、五个 BAT 入口、初始化/启停/恢复、时钟映射、状态与网络监测、离线校验及测试 |
| `robots/p450/` | 按原绝对路径镜像保存的采集入口、ROS launch/config、定位/相机/视频流启动脚本、Livox 待机控制、本地修改的上游源码、Pi05 适配器及系统配置 |
| `robots/unitree/` | 按原路径保存的采集、回放、转换、恢复、旧控制模块、手柄遥操、URDF/meshes、cuRobo 源码和已编译扩展 |
| `docs/RESTORE.md` | 恢复顺序、依赖安装、权限及安全边界 |
| `docs/DEPENDENCIES.md` | 第三方来源、版本和本地修改范围 |
| `docs/VERIFICATION.md` | 快照核验记录与尚未补齐的项目 |

`controller/remote/` 是开发用镜像；`robots/` 优先反映实际部署文件。不要用旧开发版本覆盖机器人上的更新。当前 Unitree 遥操保留已部署的关节模式限制。

## 重要边界

- **不是整机镜像，也不是完整离线安装包。** ROS、JetPack/CUDA、Conda、系统库等按依赖说明安装。
- Unitree SDK2 的大目录复制再次遇到断网，未完成的副本不提交；其精确整树备份仍待补齐。
- 旧 A800 上传入口引用的服务器端 `validate_transferred_episode.py` 不在这三台机器的已收集范围内，尚未取得；不影响当前本机控制台的录制/停止/本地对齐，但不能据此宣称旧云端上传链可直接恢复。
- P450 的 `emitter_off.json` 在原机器上已经缺失，本仓库不会虚构该配置。
- 不自动启动车辆、解锁、使能机械臂、改变网络或修复文件系统。恢复后须重新做静态检查和获授权的短测。

先阅读 [恢复说明](docs/RESTORE.md) 和 [核验记录](docs/VERIFICATION.md)。各第三方目录保留原许可证；未对整仓库重新指定统一开源许可证。
